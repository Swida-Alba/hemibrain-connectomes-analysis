#
# Step 1: Install all dependencies from this file:
#   pip install -r requirements-windows.txt
#
# Step 2: Install neuronbridge-python without dependencies:
#   pip install neuronbridge-python --no-deps
#
# Development installation (modifying the source code):
#   pip install -e .
#   pip install -r requirements-windows.txt
#   pip install neuronbridge-python --no-deps
#
# The -e flag means "editable" - changes to source files take effect immediately
# without needing to reinstall. Use this if you're developing/modifying the code.
#
# Note: This two-step process is necessary because neuronbridge-python's memray
# dependency doesn't support Windows. We install the compatible dependencies
# (pydantic, python-rapidjson, ray) first, then install neuronbridge-python
