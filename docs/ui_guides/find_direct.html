Direct Connections

Find one-hop synaptic connections between source and target neuron groups. Leave targets empty to list every downstream target of the sources.

Quick start

  1. Add Source Neurons (e.g. aMe12, aMe10).
  2. Add Target Neurons, or leave empty for all downstream targets.
  3. Click Find Direct Connections.

Inputs & examples

SituationSourceTargetResult
Specific pairaMe12aMe10Only aMe12→aMe10 edges
All downstreamaMe12, aMe10emptyEvery downstream target of both sources
Group to groupKC.*MBON.*KC → MBON edges only

Parameters

Filter BybodyIdbodyId or type aggregation
Exclude Intra-typeoffRemoves edges where type_pre == type_post
Output Formatcsvcsv or xlsx

Advanced options

  • Custom source/target names for output labels.
  • Cache Only (Offline) and Save Folder Name.
  • Hemisphere options: separate L/R, keep conserved edges, symmetry analysis.
