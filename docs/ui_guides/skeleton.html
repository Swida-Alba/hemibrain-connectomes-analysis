3D Skeleton (plot3dSkeleton)

The 3D Skeleton tab renders neuron morphology, synapses and brain region meshes from any configured dataset into an interactive HTML scene. It runs VisualizeSkeleton.plot_neurons() in the background. For pathway graphs see the separate Network guide.

Quick start

  1. In the Layer Structure tree, three layer rows are ready by default — add neurons to them, or click Add Layer for more rows.
  2. Pick the dataset; keep Brain Mesh = template and ROIs = EB, LH, AL.
  3. Click Generate 3D Skeleton.

Inputs & examples - the layer tree

The tree mirrors the script's nested-list layer model: each row is one layer and may hold several neurons (type, instance, bodyId or regex). Drag a row to reorder layers; drag a neuron chip onto another row to regroup it. Optional layer names feed the legend (unnamed layers are auto-named): the per-row name input is collapsed behind the small edit button so the rows stay compact.

The Match by mode (exact / starts with / contains / ends with / regex) converts every neuron in the tree into a regex pattern, and the Search Columns selector (auto / type / instance / bodyId) scopes name resolution — the same neuron-search backend as Find All Paths. Upload formats for neuron lists are documented in Input File Formats.

Hemisphere analysis

The Hemisphere selector (next to Search Columns) restricts the plotted neurons to one side:

  • both (default): all neurons.
  • left: only left-hemisphere neurons.
  • right: only right-hemisphere neurons.

Hemisphere assignment is automatic per neuron: the Soma side / hemisphere column wins when present, otherwise the instance suffix (_R → right, _L → left). Neurons with neither are unclassified (U) and are always included in every option — so datasets whose neurons lack hemisphere notation (e.g. some non-NeuPrint tables) are never silently dropped.

Manual suffix search still works — a chip like aMe12_R or .*_R selects one side per type; the Hemisphere selector applies the same rule to every neuron automatically, including those without a suffix.

Options

The form is organized into four independent blocks, each with its own card: General Appearance, Neuron Colors, Synapse Colors and Brain Region ROIs.

General Appearance

  • Skeleton Mode: tube (detailed) or line (fast).
  • Neuron Legend Mode: layer, type, or single. ROI meshes always keep independent legend entries.
  • Background: white or black. The default neuron palette follows it — Category10 on white, Set3 on black — until you pick a palette manually.
  • Brain Mesh: template, whole, or none; VNC Mesh toggle for male-cns/manc.

Neuron Colors

  • Neuron Opacity: global fallback opacity for skeletons (0=invisible, 1=solid).
  • Full bokeh palette catalog with custom editing. Preset palettes are picked from a full-width name dropdown; every option in the dropdown list shows the palette name with a strip preview filling the row to its right, so palettes are visible before selection. The selected palette shows in the interactive preview row, where swatches can be dragged to reorder discrete palettes, a live range slider selects part of the palette, and reset restores the original order and full range.
  • Custom colors: add colors from the native picker, free-form color formats, or individual swatches of any Bokeh palette (choose the palette in the dropdown, click a swatch to select it, then press Add color). A live square preview beside the color value shows the result with the Opacity override applied; the per-entry opacity wins over the global Neuron Opacity, while colors without an explicit opacity channel inherit it.
  • Default follows the background (Category10 / Set3) until a palette is picked manually.

Synapse Colors

  • Synapse Colors: palette for the connection markers between layers (one color per consecutive-layer pair).
  • Skip Synapses: hide markers for a clean view.
  • Min Synapse Count, Synapse Size (real or fixed), Opacity, Mode (cone or scatter).

Brain region ROIs

  • ROI Selection Mode: primary lists the common top-level brain regions; detailed lists the full dataset ROI list including non-primary sub-regions (e.g. AL-DA1(L), EBr3d) for detailed ROI selection, following the selected dataset.
  • Mesh ROIs: presets or regex (ME.*, all, primary).
  • ROI Colors: Auto gray, or any palette assigned in its exact displayed order; custom and discrete-palette reordering is preserved.
  • Each resolved ROI mesh, including bilateral expansions, is a separate trace and legend entry.
  • ROI Mesh Opacity.
  • Brain Mesh Color: swatch picker with custom color.

Advanced

  • Cache Neurons/Synapses: faster repeat renders.
  • Smooth Skeleton, Show Soma, Show Connectors.
  • Export Method: webdriver (fast, needs Chrome 109+) or kaleido (stable fallback). Export Scale and Export Views.
  • Individual Profiles: PDF/PPTX per neuron, with images per page and camera views.
  • Rotating Video / GIF: fps, degrees per frame, rotation axis, GIF scale.

Output

One timestamped folder per run, named after the dataset abbreviation and the layer names:

{output_dir}/plot-3d_MCNS_aMe12_SMP238_PPL101_20260815_151243/
    aMe12_SMP238_PPL101.html            - interactive 3D scene
    aMe12_SMP238_PPL101_neuron_info.xlsx - per-layer metadata (neuron_df{i},
                                          roi_count_df{i} sheets)
    parameters.txt                      - exact parameters of the run
    user_warning_notes.txt              - notes/warnings of the run

With Export Views on, PNG screenshots ({view}_{name}.png) are written into the same folder; the rotating Export Video adds videos/GIFs.

3D export needs Chrome when Export Method = webdriver and Export Views is on; use kaleido if Chrome is unavailable.
