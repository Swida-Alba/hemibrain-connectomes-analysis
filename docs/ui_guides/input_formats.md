# Input File Formats

## Neuron list (CSV / XLSX)

Used by Find Path, Direct Connections, Connectivity Profiling and
Cross-Dataset panels.

- **CSV / TXT**: one neuron per line, or comma-separated values. The first
  column is read as the neuron list:

  ```
  aMe12
  aMe10
  PPL101
  ```

- **XLSX**: the first column of the first sheet is read.
- Optional header names are skipped automatically:
  `type`, `neuron`, `name`, `bodyId`, `id`, `body_id`.
- Accepted entries: neuron types (`aMe12`), bodyIds
  (`720575940610453042`) and patterns (`KC.*`, `PPL.*`).

The same content can be typed chip-by-chip (Enter to add) or pasted as a
comma/newline list with the playlist button.

## Path file (Find All Paths output)

Used by the Path Network (PlotPath) panel.

- Upload the `*_allpaths_type.csv` / `*_allpaths_bodyId.csv` file (or the
  `*_allpaths_info.xlsx`) generated by **Find All Paths**.
- The file must contain a path column (`path_block` or `path`) plus
  `weights`, or an edge-list format (`source`/`target`/`weight`).

## Layer mapping CSV (3D skeleton)

Optional; each row maps a neuron to a display layer:

```csv
group,id_type_instance
Input,aMe12
Output,MBON01
```
