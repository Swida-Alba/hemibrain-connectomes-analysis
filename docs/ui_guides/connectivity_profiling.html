Connectivity Profiling

Compare connectivity profiles of neuron types (or bodyIds) inside one dataset using Jaccard, cosine and rank-correlation similarities.

Quick start

  1. Enter 2+ neurons (e.g. aMe12, aMe10, aMe9).
  2. Pick the dataset; keep Top K Partners = 15.
  3. Click Run Profiling.

Inputs & examples

QueryMeaning
aMe12, aMe10, aMe9Three types compared pairwise
720575940610453042, aMe12BodyId vs type (mixed allowed)
KC.* (Filter = Starts with)All KC types compared

Profile construction

ParameterDefaultMeaning
Top K Partners15Top partners per direction by synapse weight
Min Unique Types (M)5Minimum partner types; K expands automatically if fewer
Min Synapse Threshold3Connection weight cutoff for profiles
Aggregation Leveltypetype (grouped) or bodyid (per neuron)
Directionbothupstream, downstream, or both

Advanced options

  • BodyId-Level Computation: auto (skip over 1000 bodyIds), skip, or compute always.
  • Cluster Heatmaps (Ward): hierarchical reordering of matrices.
  • Show Figures: open heatmaps in the browser.
  • Pre-build Full Dataset Cache: OFF by default - leave it off; the tool uses connections already cached. Turning it on fetches every uncached neuron and can take hours.
