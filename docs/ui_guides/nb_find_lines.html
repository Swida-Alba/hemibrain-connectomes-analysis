Find Driver Lines

Find GAL4 / Split-GAL4 driver lines whose expression matches EM neurons, using NeuronBridge color-depth search (CDS) or point-pattern matching (PPPM).

Quick start

  1. Enter EM neurons (bodyIds, types, instances, or patterns).
  2. Keep Dataset at (all) or restrict to one dataset.
  3. Click Find Driver Lines.

Inputs & examples

QueryBehavior
aMe12Find lines labeling all aMe12 neurons
636798093Find lines for one bodyId
MBON.*Pattern across types
aMe12, MBON01Lines labeling both groups; use separate queries for different groups

Parameters

Separate Split-GAL4onGAL4/LexA and Split-GAL4 summarized separately
RegionBrainBrain, VNC, or All (image downloads)
Max Workers8Parallel API workers; lower if rate-limited
Sort Bymaxmax score or completeness (coverage)

Image download options

  • Download Images from NeuronBridge and/or From FlyLight.
  • Image Formats: png/jpg (NeuronBridge); h5j/mp4/json added for FlyLight.
  • Image Types: cdm/mip, aligned, translation, metadata.
  • Max Images / Line: download cap per line.
  • FlyLight Collections: searched in priority order; MCFO is the automatic fallback.
  • Simple Mode: fewer representative files.
  • Organize by Region: Brain/VNC subfolders.
  • PDF Summary layout and background color.

Output

The folder name uses the dataset abbreviation (MCNS = male-cns, FAFB = flywire FAFB, ...) or ALL for all-datasets searches:

{output_dir}/NB-find-lines_MCNS_aMe12_20260815_145107/
  aMe12_lines.csv            # all matched lines with scores
  line_summary.csv           # summary per line (sorted by weighted_score)
  gal4_lexa_summary.csv      # (when Split-GAL4 separation is on)
  split_gal4_summary.csv     # (when Split-GAL4 separation is on)
  parameters.json
  images/...                 # (when image download is on)
  {query}_summary.pdf        # (when a PDF/PPTX summary is requested)
Weighted score = avg match score × coverage. A line labeling all queried neurons ranks higher than one with a single high score.
