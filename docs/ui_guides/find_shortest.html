Shortest Paths

Find only the shortest (minimum hop-count) paths between source and target neuron groups. For every reachable pair, all tied shortest paths are kept. Runs on the full Find All Paths pipeline (discovery, enrichment, outputs, visualization) with shortest-only enumeration.

Quick start

  1. Add Source Neurons (e.g. aMe12, aMe10).
  2. Add Target Neurons (e.g. PPL101, DN1p).
  3. Click Shortest Paths.

Depth cap (default: 2 intermediate layers)

  • Max Intermediate Layers (optional) = 0 means unlimited search depth. Layer discovery is a BFS and stops as soon as every target has been discovered — a target's first-discovery layer is its exact shortest hop distance, so deeper layers cannot change any result.
  • The default is 2, matching the Find All Paths tab. Increase it when a query needs deeper intermediate layers; there is no artificial upper bound on the integer value.
  • Set Max Intermediate Layers > 0 only as a safety cap when targets may be unreachable (worst case: the whole forward cone of the sources is fetched).

No algorithm selector: shortest enumeration is a backward-BFS distance pass plus a guided DFS over the shortest-path DAG — polynomial in graph size. The combinatorial path explosion of Find All Paths does not exist here.
Edge Limit – BodyIds is off by default. Its purpose (bounding the exponential path count) does not apply to shortest enumeration, and trimming by strength preserves pair reachability but not shortest distance — a dropped weak edge can silently inflate a reported distance. Enable it only to cap memory on extremely large graphs; results then become shortest-within-trimmed-graph (noted in user_warning_notes.txt).

Advanced options

  • Keywords to Exclude from Paths — same semantics as Find All Paths.
  • Custom source/target names, Cache Only (Offline), Save Folder Name.
  • Hemisphere options: separate L/R labels, hemisphere filter, keep conserved edges, symmetry analysis — see Hemisphere analysis.
  • Find Reciprocal Connections — enriches the path graph with direct connections among its nodes.
