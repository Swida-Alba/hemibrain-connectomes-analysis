Tokens are saved to token_info_local.txt (gitignored) and take precedence over the template token_info.txt. For safety, the Settings page never pre-fills a saved secret into the browser. A configured (kept hidden) status means the saved value will be used; leave its field blank to keep it, or enter a new value to replace it.

Enable Clear a saved value when its field is blank only when you intentionally want to remove a token from the local file.

Test NeuPrint verifies the token by counting neurons in hemibrain:v1.2.1.

Output settings

Default Output Directory is pre-filled in every panel; change it here and click Save Default Directory. Each run creates its own timestamped subfolder.

Dataset preparation

Use the converter's directory contract exactly NeuPrint tables are fetched automatically. FlyWire/BANC datasets are prepared from raw Codex downloads placed in datasets/<dataset>/downloads/. Do not rename raw files or place them directly in the dataset root. The UI reports ✓ local only after both the generated neuron table and merged connection table exist.

NeuPrint

  1. Get a NeuPrint token from neuprint.janelia.org/account.
  2. Enter it above, click Save Tokens, then click Test NeuPrint.
  3. The selected dataset is fetched and cached automatically on first use.

FlyWire FAFB v783

Create datasets/flywire_FAFB_v783/downloads/ from the project root and keep the original compressed filenames from the Codex FAFB download.

Required raw inputs for local connection analysis:

  • classification.csv.gz
  • connections_princeton_no_threshold.csv.gz (preferred), or connections_princeton.csv.gz / connections.csv.gz as fallbacks

Recommended metadata enrichment: names.csv.gz, coordinates.csv.gz, neurons.csv.gz, cell_stats.csv.gz, and consolidated_cell_types.csv.gz. The converter can proceed without these, but labels and metadata will be incomplete.

Optional visualization inputs: fafb_v783_princeton_synapse_table.csv.gz (local synapses) and sk_lod1_783_healed.zip (local skeletons).

python src/FAFB_file_converter.py

Or select flywire_FAFB_v783 in a tool and run it; the tool invokes the same local preparation automatically. Verify that the root contains flywire_FAFB_v783_allneurons_neuron_df.parquet and flywire_FAFB_v783_merged_connections.parquet, then click Refresh.

FlyWire BANC v888 / v626

Choose exactly one identifier and do not mix versions. Create datasets/flywire_BANC_v888/downloads/ or datasets/flywire_BANC_v626/downloads/ and place the original Codex files from the BANC download there:

  • neurons.csv.gz
  • connections_princeton.csv.gz

Do not manually create or rename a *_allneurons_neuron_df.csv file; that is generated output. Convert v626 with:

python src/BANC_file_converter.py

For v888, run the converter with the selected dataset name:

python -c "import sys; sys.path.insert(0, 'src'); from BANC_file_converter import ensure_banc_data; d='flywire_BANC_v888'; ensure_banc_data(d, 'datasets/' + d)"

Verify that the selected root contains both <dataset>_allneurons_neuron_df.parquet and <dataset>_merged_connections.parquet, then click Refresh. BANC skeleton visualization and CAVE API fetching are not supported; use the converted local files for pathfinding, networks, and tabular analysis.

CAVE token scope A CAVE token is needed only for workflows that explicitly fetch FAFB data or skeletons through CAVE. It does not replace the local input files, and a token alone does not prepare a FlyWire dataset.
