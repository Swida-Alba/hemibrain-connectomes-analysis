Test NeuPrint verifies the token by counting neurons in hemibrain:v1.2.1.

Dataset availability

Click Refresh to query the server for available datasets. The status column shows:

StatusMeaning
✓ localFull local data files ready
◐ cachedPartial local cache exists
☁ serverAvailable online (token required)
not readyNo token or no data

Output settings

Default Output Directory is pre-filled in every panel; change it here and click Save Default Directory. Each run creates its own timestamped subfolder.

Dataset preparation

  • NeuPrint: downloaded automatically on first use (needs token + network).
  • FlyWire FAFB/BANC: download the neuron-table CSV from codex.flywire.ai, save it as datasets/flywire_FAFB_v783/flywire_FAFB_v783_allneurons_neuron_df.csv (similar for BANC), and provide a CAVE token.
