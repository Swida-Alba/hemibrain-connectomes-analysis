Cross-Dataset Comparison

Analyze one dataset across multiple synapse thresholds, or compare connectivity between two or more datasets (e.g. male-cns:v0.9 vs hemibrain:v1.2.1) for the same source → target query.

Quick start

  1. Select one or more Datasets. One dataset with multiple thresholds is also supported; select multiple datasets for cross-dataset comparison.
  2. Add Source Neurons and Target Neurons.
  3. Click Run Comparison - a report plus matrices are produced for every threshold.

Parameters

ParameterDefaultMeaning
Path Enumerationallall: every path within the layer limit (FindAllPath). shortest: only the per-(source, target) minimum-hop paths (FindShortestPath); discovery stops early once all targets are found, and Max Intermediate Layers 0 means unlimited depth.
Max Intermediate Layers2Path depth for path mode. In shortest mode an optional safety cap: 0 = unlimited.
Top Edges in Analysis Reports500Limits top-edge comparison/overlap results, edge/path presence-matrix rows, and path-presence data used by comparison summary plots; it does not trim pathfinding or set the per-visualization drawn-edge cap
Edge Limit – BodyIds1,000,000Trims the bodyId discovery graph before pathfinding for deep searches (Layers ≥ 3); 0 = no graph trimming, while a positive cap can change path results
Visualization Edge Limit500Caps edges drawn in each network/Sankey/heatmap visualization; it does not alter fetched connections or pathfinding
Pathfinding AlgorithmMemoizedDFSAlgorithm used per dataset (not used by shortest enumeration). See the pathfinding algorithms guide: MemoizedDFS is fastest at all depths; DFS for few targets; MeetInMiddle for shallow queries.
Search ColumnsautoColumns searched when resolving source/target names in every dataset: auto = all columns (bodyId → type → instance → flywireType/hemibrainType/…), or restrict to type / instance / bodyId. Use auto when names come from a cross-dataset type column (e.g. MTe07 in flywireType on male-cns v1.0).

Advanced options

  • Skip BodyId Level: type-level only (faster, recommended).
  • Cache Only (Offline): no server contact; requires caches.
  • Auto Type Mapping: map equivalent type names across datasets.
  • Parallel Processing / Max Workers: tune speed vs API load.
  • Hemisphere analysis: L/R separation, symmetry, conserved edges, reciprocal graphs.
