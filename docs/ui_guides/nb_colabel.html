Co-Labeling Analysis

Analyze overlap between driver lines: which neuron types each line labels, Jaccard / weighted-Jaccard co-labeling matrices, and line specificity.

Quick start

  1. Enter at least two Driver Lines (e.g. VT037867, R10A06).
  2. Keep Jaccard and Weighted Jaccard enabled.
  3. Click Run Co-Labeling.

Parameters

ParameterDefaultMeaning
Similarity methodsjaccard, weighted_jaccardBinary vs score-weighted overlap
Top N Neurons Per Line200Neurons considered per line
Min Match Score20000Minimum NeuronBridge score to include a neuron
Min Type Avg Score10000Minimum average score to include a type
Heatmaps / HTML ReportonInteractive outputs
3D SkeletonoffRender top co-labeled types

Output

{output_dir}/NB-colabeling_{lines}_{timestamp}/
  colabeling_matrix_jaccard.csv
  colabeling_matrix_weighted_jaccard.csv
  expression_matrix.csv
  line_summary.csv            (specificity statistics)
  colabeling_report.html
Line specificity is high when a line labels few distinct types - useful for identifying selective drivers.
