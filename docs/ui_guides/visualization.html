3D Skeleton + Network

Two top-level tabs: 3D Skeleton (plot3dSkeleton) for neuron morphology and Network (PlotPath) for pathway graphs. Each tab has its own run action, log, and output files.

Quick start - 3D skeleton

  1. Add neurons/layers as chips (e.g. aMe12 or aMe12 -> MBON01).
  2. Pick the dataset; keep Brain Mesh = template and ROIs = EB, LH, AL.
  3. Click Generate 3D Skeleton in the 3D Skeleton tab.

Quick start - path network

  1. Run Find All Paths first.
  2. Upload its *_allpaths_type.csv (or *_allpaths_info.xlsx) file.
  3. Click Generate Network in the Network tab.

Quick start - empty drawing canvas

  1. Open the top-level Network tab.
  2. Set Canvas Source to Empty drawing canvas; no path file is required.
  3. Click Generate Network and open the generated HTML.
  4. Enable Edit Mode, add nodes, and connect them directly on the canvas.
  5. For a one-click workflow, use Create Empty Canvas; it generates the HTML and opens it in a new browser tab automatically.

The neuron input also has a Filter mode (exact / starts with / contains / ends with / regex) that converts every chip into a regex pattern, and a Search Columns selector (auto / type / instance / bodyId) — the same neuron-search backend as Find All Paths.

3D skeleton - hemisphere analysis

The Hemisphere selector (next to Search Columns) restricts the plotted neurons to one side:

  • both (default): all neurons.
  • left: only left-hemisphere neurons.
  • right: only right-hemisphere neurons.

Hemisphere assignment is automatic per neuron: the Soma side / hemisphere column wins when present, otherwise the instance suffix (_R → right, _L → left). Neurons with neither are unclassified (U) and are always included in every option — so datasets whose neurons lack hemisphere notation (e.g. some non-NeuPrint tables) are never silently dropped.

Manual suffix search still works — a chip like aMe12_R or .*_R selects one side per type; the Hemisphere selector applies the same rule to every neuron automatically, including those without a suffix.

3D skeleton - options

The form is organized into four independent blocks, each with its own card: General Appearance, Neuron Colors, Synapse Colors and Brain Region ROIs.

General Appearance

  • Skeleton Mode: tube (detailed) or line (fast).
  • Neuron Legend Mode: layer, type, or single. ROI meshes always keep independent legend entries.
  • Neuron Opacity.
  • Background: white or black. The default neuron palette follows it — Category10 on white, Set3 on black — until you pick a palette manually.
  • Brain Mesh: template, whole, or none; VNC Mesh toggle for male-cns/manc.

Neuron Colors

  • Full bokeh palette catalog with custom editing. One interactive preview row shows the current state: drag swatches to reorder discrete palettes, a live range slider selects part of the palette, and reset restores the original order and full range.
  • Default follows the background (Category10 / Set3) until a palette is picked manually.

Synapse Colors

  • Synapse Colors: palette for the connection markers between layers (one color per consecutive-layer pair).
  • Skip Synapses: hide markers for a clean view.
  • Min Synapse Count, Synapse Size (real or fixed), Opacity, Mode (cone or scatter).

Brain region ROIs

  • Mesh ROIs: presets or regex (ME.*, all, primary).
  • ROI Colors: Auto gray, or any palette assigned in its exact displayed order; custom and discrete-palette reordering is preserved.
  • Each resolved ROI mesh, including bilateral expansions, is a separate trace and legend entry.
  • ROI Mesh Opacity.

3D skeleton - advanced

  • Cache Neurons/Synapses: faster repeat renders.
  • Smooth Skeleton, Show Soma, Show Connectors.
  • Export Method: webdriver (fast, needs Chrome 109+) or kaleido (stable fallback). Export Scale and Export Views.
  • Brain Mesh Color: swatch picker with custom color.
  • Individual Profiles: PDF/PPTX per neuron, with images per page and camera views.
  • Rotating Video / GIF: fps, degrees per frame, rotation axis, GIF scale.

Path network - options

  • Canvas Source: load a Find All Paths file or create an empty interactive drawing canvas.
  • Color Scheme: swatch-preview schemes for source/intermediate/target/link.
  • Network Layout: hierarchical, spring, circular, distributed.
  • Interactive HTML and XLSX connection tables are always generated.
