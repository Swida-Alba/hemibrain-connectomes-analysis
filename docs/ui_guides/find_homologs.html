Homolog Finding

Find potential cross-dataset homologs of a source neuron via connectivity profile similarity, e.g. aMe12 in male-cns → candidates in hemibrain.

Quick start

  1. Enter one or more Source Neurons (types or bodyIds). Each input is searched independently and receives its own output folder.
  2. Choose Source Dataset and Target Dataset.
  3. Click Find Homologs (Fast Search is on by default).

Parameters

ParameterDefaultMeaning

Top K Partners15Partners per direction in the profile

Sort BycosineOrdering metric for the candidate list (top-N cut) — jaccard, cosine, rank_corr, rank_union. Sorting only: ALL metrics are always computed (same backend as Connectivity Profiling).

Options

  • Fast Search: adjacency-expansion discovery (recommended).
  • Vector Pre-filtering: cosine pre-filter for speed.
  • 2-Hop Expansion: include untyped partners via 2-hop typed partners.
  • Visualize Candidates: render the queried neuron plus the top-N matches as 3D skeletons. For cross-dataset searches, the query is shown in the source-dataset visualization and matches in the target-dataset visualization.
  • Analysis visualizations default to Skeleton Mode = line for speed. For high-quality morphology, use Visualization → Skeleton, or select tube with the fine method and 95% simplification in the advanced visualization settings.
  • Auto Type Mapping: canonicalize partner type names across datasets (recommended for cross-dataset searches).
  • Pre-build Full Dataset Cache: leave OFF; the search fetches what it needs.

Loose search (more candidates)

The loose-search knobs (Min Shared Partners, Candidate Prune %) now live on the Similar tab (connection-profile mode). The backend parameters (min_shared_partners, vector_prune_fraction) remain supported programmatically: lower the shared-partner threshold (1 = any shared partner) and raise the prune fraction (1.0 = keep all cosine-positive candidates) to widen the candidate pool while keeping the same adjacency-expansion hops.

Output

Each run is saved in its own timestamped folder named after the query and the dataset abbreviations (MCNS = male-cns, FAFB = flywire FAFB, ...); the Save Folder Name field overrides this:

{output_dir}/homologs_MCNS_to_FAFB_aMe12_20260815_143540/
  README.txt
  results/
    homolog_results.csv          # full ranked results (all metrics)
    bodyid_results.csv           # bodyId-level results
    type_summary.csv             # type-level summary
    source_status_summary.json   # per-source-neuron status
  profiles/
    query/{type}.csv, query/source_bodyids.csv
    matches/{type}.csv, matches/top_target_bodyids.csv
  overlaps/{source}_vs_{target}.csv    # partner overlap details
  visualization/...            (when visualization enabled)
Exported run guide: every successful run also writes _UserGuide_please_read_me.html into the run folder — a self-contained explanation of every output file, every table column, and any warnings recorded for the run. Format (html / txt / markdown / disabled) is set in Settings → Default Settings → Run Guide Format.
