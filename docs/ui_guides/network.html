Network (PlotPath)

The Network tab turns pathway data into interactive graphs: a Sankey flow diagram, a connection heatmap and a draggable Cytoscape network, plus an editable empty drawing canvas. It runs vispath_pkg.VisualizePath in the background. For neuron morphology see the separate 3D Skeleton guide.

Quick start - path network

  1. Run Find All Paths first.
  2. Upload its *_allpaths_type.csv (or *_allpaths_info.xlsx) file.
  3. Click Generate Network.

Quick start - edge list editor

  1. In the Edge List Editor card (always visible below the source card), enter a Draft Name, click Add Edge, fill source / target / weight in the edit row and click Apply to Selected.
  2. Set Canvas Source to Edge list editor (opening the editor also selects it) and click Generate Network - the draft is auto-saved and used directly as the network input.

Quick start - empty drawing canvas

  1. Click the standalone Create Empty Canvas button in the Net-Viz Source card; no path file and no Canvas Source change is required. It generates the HTML and opens it in a new browser tab automatically.
  2. Enable Edit Mode, add nodes, and connect them directly on the canvas.

Network input files - full specification

The upload button accepts CSV, XLSX and XLS files. The backend (VisualizePath) auto-detects one of three data formats inside the file, so you can feed it Find All Paths output, a simple edge list, or a connection matrix. Only one file is loaded at a time; uploading a new file replaces the previous one.

Format 1 - Path-based (Find All Paths output)

Each row is one complete multi-hop path. This is the format produced by the Find All Paths tab.

ColumnRequiredAccepted namesMeaning
Path yes path_block, path, path_str Ordered node sequence, e.g. A->B->C. Aliases are renamed to path_block automatically.
Weights yes weights List of per-hop weights (synapse counts), e.g. [10, 5]. Length must equal number of nodes − 1.
Connection ratios optional connection_ratios, ratio, ratios, connection_ratio, conn_ratio Per-hop connection ratios (case-insensitive match).
Traversal probabilities optional traversal_probabilities, probability, probabilities, prob, traversal_probability, trav_prob Per-hop traversal probabilities (case-insensitive match).
Layer optional layer Layer annotation kept for downstream analysis.
Minimal path-based CSV
path,weights
aMe12->aMe10->MBON01,"[128, 47]"
aMe12->PPL101->MBON01,"[63, 22]"

Two 2-hop paths. Weights are the synapse counts of each hop; here min_weight would be 47 and 22 respectively.

Find All Paths files at a glance

FileContent
{source}_to_{target}_allpaths_type.csv Type-level paths (recommended for visualization).
{source}_to_{target}_allpaths_bodyId.csv bodyId-level paths (finer grain, more rows).
{source}_to_{target}_allpaths_info.xlsx Excel workbook; the path_type / path_bodyId sheets hold the same tables.

Columns of the path tables: path_str (node list), path (A->B->C string), weights, probabilities, ratios, min_weight (bottleneck synapse count), path_prob (product of hop probabilities), min_ratio, length (number of hops). Extra columns are ignored, so the files can be filtered/sorted (e.g. keep only rows with min_weight ≥ 10) and re-uploaded as-is.

Format 2 - Edge list

Each row is one directed connection; the network is built directly from the edges (every edge becomes a 1-hop path). Detection accepts these column sets:

  • source / target / weight
  • from / to / weight
  • pre / post / weight
  • Any {prefix}_pre + {prefix}_post + weight combination, e.g. bodyId_pre, bodyId_post, weight (the connection tables cached by DROCAT use this layout).

The weight column may also be named weights, synapse_count or count. An optional color / edge_color / link_color column assigns a per-edge color (hex or rgba).

Expanded edge list (Edge List CSV export). The file written by the in-HTML 📋 Edge List CSV button (see Export edge list as CSV) can be re-uploaded as-is - it round-trips back into the same network. The extra columns are handled as follows:

ColumnOn re-import
source / target / weight Required; the edges of the network (signed weights allowed).
color Per-edge color (hex or rgba).
nt_type Neurotransmitter type; drives NT-based edge coloring (empty = unknown).
source_group / target_group Restores the source / intermediate / target classification of each endpoint node. Without them a plain edge list would classify every node as source.
ratio / probability Mapped back to the standard connection-ratio and traversal-probability metric columns.
nt_group / custom_groups Informational; accepted and ignored (NT grouping is re-derived from nt_type).

Format 3 - Connection matrix

A 2D numeric table where rows are pre-synaptic and columns are post-synaptic nodes. Every non-zero cell becomes an edge. In a CSV the first text column is used as the row labels; column headers are the target labels. If labels are missing, nodes are named N0, N1, ....

Matrix CSV
,aMe10,PPL101,MBON01
aMe12,0,63,0
aMe10,0,0,47
PPL101,0,0,22

Excel sheet selection

For workbooks the sheet is chosen automatically in this priority order: path_type → path_bodyId → path_block → paths. A workbook with a single sheet uses that sheet; any other sheet layout falls back to the first sheet when run from the UI. For CSV files no sheet selection applies.

Common mistakes - Uploading a path file with a path column but no weights column (both are required). - A weights list whose length does not match the number of hops (nodes − 1). - Saving CSV with BOM/UTF-16 - use UTF-8. - Expecting an edge list named pre_syn/post_syn to work without a weight column.

Edge list editor - auto-save & recovery

The editor builds a Format-2 edge list interactively and persists every change automatically:

  • Auto-save: about half a second after the last edit the draft is flushed atomically to local_data/edge_list_drafts/ ({name}.csv + a metadata sidecar). If the UI or its port shuts down accidentally, nothing is lost.
  • Unsaved reminder: a draft stays marked as pending export until you click Export CSV. On the next start, the Network tab shows a recovery banner listing every draft with pending edits; each has a Recover button that loads it back into the editor.
  • Editing: select table rows to load them into the edit row, apply changes, add or delete edges. Renaming a draft moves it (the old draft is removed). Delete Draft removes it from disk.
  • Running: with Canvas Source = Edge list editor, Generate Network flushes the draft and feeds its CSV straight to PlotPath, so the draft must contain at least one complete edge (source, target, weight).
  • Export CSV downloads the draft as {name}_edge_list_{timestamp}.csv through the browser; when a Path Output Directory is set, a local copy with the same timestamped name is saved there too. The pending-export marker is cleared.

Rendering options

  • Canvas Source: Path file (load Find All Paths output or any format above) or Edge list editor (build/edit an auto-saved edge list). The empty drawing canvas is created with the standalone Create Empty Canvas button next to the selector.
  • Path Output Directory: every run creates its own plot-network_{name}_{timestamp}/ subfolder inside it.
  • Network Layout: hierarchical (default), spring, circular, shell, or distributed.
  • Color Scheme: swatch-preview presets (Cool, Default, Warm, Purple) for source / intermediate / target nodes and links.
  • Open in Browser: open the HTML results right after the run.

The network view shows at most the 500 strongest edges (source/target connections are always kept); the exported data files always contain the complete table.

Working with the generated network HTML

  • Explore: drag nodes, hover for weight/probability tooltips, click a node or edge to highlight its neighborhood, right-click to hide elements.
  • Adjust: live sliders for node size, font size and edge width; toggle orphan nodes, self-loops and dead ends; re-run the layout.
  • Color: restyle selected elements or whole groups (source / intermediate / target nodes, all edges).
  • Edit Mode (empty canvas): add nodes, drag from one node to another to connect them, double-click to edit properties, right-click to delete. Every action is recorded - use Undo/Redo or the history list to jump between states.
  • Save your work: Save/Load layout, Export/Import graph (JSON), export the edge list as CSV, and export the figure as PNG or SVG.

Export edge list as CSV

The 📋 Edge List CSV button in the Export panel downloads every edge of the current graph - including everything changed in Edit Mode (edited weights, recolored edges, added/deleted edges, relabeled nodes). The file always contains the complete edge table, even when the view is filtered or elements are hidden. The file is a valid Format-2 edge list: upload it again in the Net-Viz tab to rebuild the same network (edges, colors, NT types, metric columns and the source/intermediate/target node grouping).

ColumnContent
source / target / weight Edge endpoints (current node labels) and the signed weight - directly re-importable as a Format-2 edge list.
color The edge's current color (hex); recognized on re-import.
nt_type / nt_group Neurotransmitter type and its group (excitatory / inhibitory / modulatory / unknown). nt_type is recognized on re-import.
source_group / target_group Node group of each endpoint (source / intermediate / target).
custom_groups Semicolon-separated names of custom groups containing the edge.
ratio / probability Connection ratio and traversal probability when present; empty otherwise. Mapped back to the standard metric columns on re-import.
