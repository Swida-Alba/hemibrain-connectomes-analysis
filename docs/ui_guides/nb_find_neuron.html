Find EM Neurons

Find EM neurons whose morphology matches a GAL4 / Split-GAL4 driver line.

Quick start

  1. Enter one or more Driver Line Names (e.g. VT037867, R10A06, SS00731).
  2. Click Find EM Neurons.

Inputs & examples

Line nameType
VT037867VT GAL4 line
R10A06Gen1 GAL4 line
SS00731Split-GAL4 line

Multiple names can be comma/newline separated; each line is processed independently.

Parameters

ParameterDefaultMeaning
Algorithmcdscds, pppm, or both
Top N Results20Matched neurons returned per line
Visualize Top NeuronsonRender top matches in 3D
Visualize BytypeGroup visualizations by type or bodyId
Sort Bymax_scoremax_score or type_avg_score
PDF SummaryonIndividual profile PDF/PPTX
Result visualizations default to Skeleton Mode = line for speed. For high-quality morphology, open Visualization → Skeleton, or select tube with the fine method and 95% simplification.

Output

{output_dir}/NB-find-neurons_SS01015_20260815_143937/
  all_neurons.csv                       # combined matches across datasets
  {line}_neurons.csv                    # all matches for the line
  {line}_{dataset_folder}_neurons.csv   # per-dataset matches
  {line}_{dataset_folder}_types.csv     # per-dataset type aggregates
  {line}_type_mapped.csv                # cross-dataset type mapping
  labeling_distribution.html            # score distribution
  parameters.json
  plot-3d_{dataset}/...                 # 3D views (when Visualize Top N > 0)
  individual_profiles/...               # PDF/PPTX (when enabled)
