# Output Files Documentation

This document explains the output files generated by the core modules of the Hemibrain Connectomes Analysis pipeline.

> **Verified 2026-08-15** — every structure below was verified against real outputs produced by the overall lite end-to-end suite (`tests/e2e/run_overall_lite_e2e.py`, 20 runs across all 13 scenarios: Complete/Shortest Paths, Find Network, Cross-Dataset Comparison, 3D Skeleton, Net-Viz, Homologs, Similar Neurons (morphology + connectivity), Profiling, NeuronBridge find lines/neurons/co-labeling, and FlyLight downloads). Timestamps below are abbreviated as `{ts}` (`YYYYMMDD_HHMMSS`).

## Naming Conventions

*   `{ABBREV}` — dataset abbreviation used in folder names: `MCNS` (male-cns), `FAFB` (flywire FAFB), `HEMI` (hemibrain), `MANC` (manc), `OLOB` (optic-lobe). BANC appears as `B_v626` / `B_v888`.
*   `{ts}` — run timestamp, `YYYYMMDD_HHMMSS`.
*   Every tool writes its outputs into its own timestamped run folder inside the user-chosen output directory.

## Local Dataset Files (NeuPrint)

Pulled NeuPrint datasets are stored under `datasets/<dataset>/` with a
`<dataset>_metadata.json` sidecar:

*   **`<dataset>_metadata.json`**: Written by `statvis.pull_dataset` from
    the frames it just pulled (neuron/typed counts, synapse totals, primary
    ROI list and per-ROI neuron counts, coverage notes), so every pulled
    dataset carries its statistics regardless of whether a cross-dataset
    comparison has ever run.
*   **`<dataset>_allneurons_neuron_df.csv`**: Full neuron table (one row per
    bodyId, including untyped neurons).  Since 2026-08 the per-neuron ROI
    columns `roiInfo`, `inputRois` and `outputRois` are **not saved by
    default** — they are redundant with the roi-count file and, for
    male-cns, accounted for ~90% of the CSV size.  `statvis.pull_dataset`
    drops them via `drop_roi_cols=True`; pass `drop_roi_cols=False` to keep
    the raw columns locally.
*   **`<dataset>_allneurons_roi_count_df.csv`**: Long-form per-ROI synapse
    counts (one row per bodyId × ROI, plus a computed `NotPrimary` row per
    neuron).  This is the source of truth for ROI data; the three dropped
    columns are fully derivable from it:
    *   `inputRois` = ROIs where `post > 0`
    *   `outputRois` = ROIs where `pre > 0`
    *   `roiInfo` = per-bodyId pivot of `pre`/`post`/`downstream`/`upstream`,
        with `synweight = post + downstream`

## 1. Complete Paths and Shortest Paths (FindNeuronConnection)

The `FindNeuronConnection` class (in `src/coana.py`) is the core pathfinding engine. `FindAllPath` ("Complete Paths" tab) and `FindShortestPath` ("Shortest Paths" tab) share the same output layout.

### Folder Structure

`find-paths-complete_{ABBREV}_{source}_to_{target}_L{max_interlayer}w{min_weight}r{min_ratio}p{min_prob}_{ts}/`
(`find-paths-shortest_...` for the shortest-path mode.)

Example: `find-paths-complete_MCNS_aMe12_to_PPL101_L1w3r0p0_20260815_142520/`

### Key Output Files

#### Main Data Files
*   **`{source}_to_{target}_allpaths_type.csv`**: The primary path table (type-level when `skip_bodyId=True`, the UI default). Columns:
    *   `path`: Path as a type sequence (e.g. `aMe12 → SMP238 → PPL101`)
    *   `weights`, `probabilities`, `ratios`: Per-edge synapse counts, traversal probabilities, and connection ratios
    *   `min_weight`: Smallest edge weight along the path
    *   `path_prob`: Overall path probability
    *   `min_ratio`: Smallest edge connection ratio
    *   `length`: Number of hops
    *   `nt_types`: Neurotransmitter types along the path
*   **`all_attributes.json`**: Serialized run attributes.

#### Supporting Data (`data_details/`)
*   **`conn_mat_type_weight.csv` / `conn_mat_type_ratio.csv` / `conn_mat_type_prob.csv` / `conn_mat_type_nt.csv`**: Type-level weight / ratio / traversal-probability / neurotransmitter matrices
*   **`connection_type.csv`**: Edges aggregated by type pair — columns `type_pre`, `type_post`, `weight`, `connection_ratio`, `traversal_probability`, `block_probability`, `nt_type`
*   **`source_neurons.csv` / `target_neurons.csv`**: Resolved source / target neuron metadata
*   **`neurons_included.csv`**: All neurons participating in the found connections
*   **`total_weight_layer.csv`**: Total weight per intermediate layer
*   **`parameters.csv`**: Parameters of the run

#### Visualizations (`visualization/`)
*   **`Network_{folder}.html`**: Interactive network graph of the found paths
*   **`Heatmap_{folder}.html`**: Connection weight heatmap
*   **`Sankey_{folder}.html`**: Sankey flow diagram of the pathways
*   **`visualization_data/{folder}_data_connections.csv` / `{folder}_data_original_paths.csv`**: Data backing the HTML files

#### Run Metadata
*   **`parameters.txt`**: Human-readable record of all parameters
*   **`user_warning_notes.txt`**: Warnings/notes collected during the run (e.g. skipped filters, edge trimming)

#### Hemisphere Symmetry (`hemisphere_symmetry/`)
Written when `symmetry_analysis=True` (enabled together with the Hemisphere-aware checkbox):
*   **`symmetry_summary.json`**: Ipsilateral/contralateral Jaccard and conserved/union counts
*   **`symmetry_ipsi.csv`**: L-L vs R-R edge comparisons
*   **`symmetry_contra.csv`**: L-R vs R-L edge comparisons
*   **`conserved_edges.csv`** / **`unconserved_edges.csv`**: Hemisphere-conserved vs unconserved edge lists
*   **`pairwise_strength.csv`**: Weight comparisons for matched hemisphere edge pairs
*   **`type_counts_by_role.csv`**: Per-type source/intermediate/target counts

#### Reciprocal Connections (`find_reciprocal/`)
Written when `find_reciprocal=True`:
*   **`reciprocal_connection_type.csv`**: Type-level reciprocal connections
*   **`reciprocal_type_network.html`** / **`reciprocal_type_heatmap.html`**: Reciprocal visualizations
*   **`parameters.csv`**: Reciprocal-analysis parameters

> ℹ️ **Parameter Calculations**: See [ScoreCalculation_Guide](core-features/ScoreCalculation_Guide.md) for formulas explaining `connection_ratio`, `traversal_probability`, and filtering thresholds.
>
> ℹ️ With `skip_bodyId=False`, bodyId-level tables (`{source}_to_{target}_allpaths_bodyId.csv`) are written alongside the type-level ones; with `output_format='xlsx'`, tables are written as multi-sheet Excel workbooks. The structure above reflects the UI defaults (`skip_bodyId=True`, `output_format='csv'`).

## 2. Find Network (FindNeuronConnection.FindNetwork)

The "Network" tab resolves one query set (patterns supported, e.g. `aMe.*`) and finds direct connections among the matched neurons.

### Folder Structure

`find-network_{ABBREV}_{query_name}_w{min_weight}r{min_ratio}p{min_prob}_{ts}/`

Example: `find-network_MCNS_aMe_w3r0p0_20260815_142745/`

### Key Output Files
*   **`data_details/connection_type.csv`**: Direct connections aggregated by type pair (same columns as Section 1)
*   **`data_details/neurons.csv`**: The resolved neuron set
*   **`data_details/parameters.csv`**, **`parameters.txt`**, **`all_attributes.json`**, **`user_warning_notes.txt`**: Run metadata
*   **`visualization/Network_{folder}.html`** / **`Heatmap_{folder}.html`**: Network and heatmap views (no Sankey in network mode)
*   **`visualization/visualization_data/{folder}_data_connections.csv`**, **`{folder}_data_original_paths.csv`**, **`network_edges_input.csv`**: Data backing the HTML files

## 3. 3D Skeleton Visualization (VisualizeSkeleton)

The `VisualizeSkeleton` class (in `src/visualize_skeleton.py`) generates 3D visualizations of neuron skeletons, synapses, and ROIs.

### Folder Structure

`plot-3d_{ABBREV}_{layer_names}_{ts}/`

Example: `plot-3d_MCNS_aMe12_SMP238_PPL101_20260815_151243/` (layer names joined with `_`)

### Key Output Files
*   **`{layer_names}.html`**: The interactive 3D visualization. Open in a web browser to view neurons, synapses, and ROIs.
*   **`{layer_names}_neuron_info.xlsx`**: Excel workbook with per-layer sheets:
    *   `neuron_df{i}` / `roi_count_df{i}`: Neuron metadata and per-ROI synapse counts for layer *i*.
*   **`parameters.txt`**: Visualization parameters (colors, alphas, modes, backend, etc.)
*   **`user_warning_notes.txt`**: Notes/warnings collected during rendering
*   When `export_views=True` (or a view list) or `export_video=True` is requested, PNG screenshots and/or videos/GIFs are written into the same folder.

## 4. Net-Viz (VisualizePath)

The Net-Viz tab (`vispath-subproject/src/vispath_pkg/vispath.py`) renders pathway graphs from Complete Paths output files or from a custom edge-list CSV (columns `source,target,weight`, optional `color`).

### Folder Structure

`plot-network_{name}_{ts}/`

Example: `plot-network_custom_edgelist_20260815_142334/`

### Key Output Files
*   **`{base}_network.html`**: Interactive pathway graph
*   **`{base}_heatmap.html`**: Edge weight heatmap
*   **`{base}_Sankey.html`**: Sankey flow diagram
*   **`{base}_data.xlsx`**: Workbook with sheets `connections`, `original_paths`, `connMatrix_weight`, `connMatrix_ratio`, `connMatrix_prob`
*   The "Create Empty Canvas" mode writes only an HTML drawing canvas.

## 5. Homolog Finding (HomologFinder)

The `HomologFinder` (in `src/comparison/profile_comparator.py`) finds potential homologs across (or within) datasets.

> 📖 **See Also**: [HomologFinding_Guide](core-features/HomologFinding_Guide.md) for usage examples and the 1-hop/2-hop hybrid profile approach.

### Folder Structure

`homologs_{SRC_ABBREV}_to_{TGT_ABBREV}_{query}_{ts}/`

Example: `homologs_MCNS_to_FAFB_aMe12_20260815_143540/`

### Key Output Files

#### Results (`results/`)
*   **`homolog_results.csv`**: Full results with all similarity columns, sorted by the chosen metric.
*   **`bodyid_results.csv`**: BodyId-level results (sorted by source, then metric).
*   **`type_summary.csv`**: Aggregated results at the neuron type level.
*   **`source_status_summary.json`**: Per-source-neuron status (resolved bodyIds, candidate counts).

#### Profiles (`profiles/`)
*   **`query/{type}.csv`** and **`query/source_bodyids.csv`**: Connectivity profiles of the query neuron(s)
*   **`matches/{type}.csv`** and **`matches/top_target_bodyids.csv`**: Profiles of the top candidate matches

#### Overlaps (`overlaps/`)
*   **`{source}_vs_{target}.csv`**: Partner overlap details for top candidates (which partners are shared vs unique).

#### Metadata
*   **`README.txt`**: Analysis parameters, summary, and column descriptions.

## 6. Find Similar Neurons

Two similarity modes share the "Find Similar" tab.

### 6a. Morphological Similarity (MorphologyComparer)

Finds morphologically similar neurons (vectorized skeleton comparison).

### Folder Structure

`similar-morphology_{dataset}_{query}_{ts}/`

Example: `similar-morphology_flywire_FAFB_v783_aMe12_20260815_143601/`

### Key Output Files
*   **`results.csv`**: BodyId-level similarity results
*   **`type_summary.csv`**: Type-level summary
*   **`README.txt`**: Run summary

### 6b. Connection Profile Similarity (HomologFinder)

Finds connectivity-similar neurons (same engine as Section 5, prefixed `similar-connectivity`).

### Folder Structure

`similar-connectivity_{SRC_ABBREV}_to_{TGT_ABBREV}_{query}_{ts}/`

Example: `similar-connectivity_FAFB_to_FAFB_aMe12_20260815_143654/`

### Key Output Files
Same layout as Section 5, plus:
*   **`results/intra_type_results.csv`**: Intra-type comparison table (written for same-dataset searches).

## 7. Cross-Dataset Comparison (ComparisonAnalyzer)

The `ComparisonAnalyzer` (in `src/comparison/comparison_analyzer.py`) compares connectivity pathways across multiple datasets.

> 📖 **See Also**: [CrossDatasetComparison_Guide](core-features/CrossDatasetComparison_Guide.md) for comparison modes, calculated parameters, and HTML report features.

### Folder Structure

`cross-dataset_{source}_to_{target}_{dataset_codes}_{ts}/`

Example: `cross-dataset_aMe12_to_PPL101_MFB_v626B_v888_20260815_142812/` (male-cns v1.0 + FAFB v783 + BANC v626 + BANC v888)

### Key Output Files

#### Main Reports
*   **`comparison_report.html`**: Comprehensive interactive HTML report (summary statistics, per-dataset networks, Sankey comparisons, presence heatmaps)
*   **`comparison_report.txt`**: Plain text summary
*   **`parameters.json`**: JSON dump of all `ComparisonParameters` (metadata, datasets, resolved source/target groups, thresholds, algorithm and feature flags)
*   **`label_map.json`**: Label mappings for source/target neurons across datasets (includes `metadata.auto_type_mapping`)
*   **`dataset_metadata_comparison.csv`**: Per-dataset metadata comparison (also present under `comparison_results/`)
*   **`auto_type_mapping.csv`** / **`auto_type_mapping_conflicts.csv`**: Cross-dataset type mapping tables (see [AUTO_TYPE_MAPPING](AUTO_TYPE_MAPPING.md))

#### Report Data (`comparison_report_used_data/`)
*   **`avg_prob_data.csv`**, **`avg_ratio_data.csv`**, **`edge_count_data.csv`**, **`total_weight_data.csv`**: Aggregated metrics per dataset
*   **`ratio_data_t{N}.csv`**: Ratio data for threshold N

#### Comparison Results (`comparison_results/`)
*   **`edge_presence_matrix.csv`** / **`edge_presence_matrix_minsyn_{N}.csv`**: Edge presence across datasets (per threshold N)
*   **`edge_weight_comparison.csv`**: Edge weights compared across all datasets
*   **`path_presence_matrix.csv`** / **`path_presence_matrix_minsyn_{N}.csv`**: Path presence across datasets
*   **`unified_edge_comparison.csv`** / **`unified_summary.csv`**: Combined edge data and run summary
*   **`unique_to_{dataset}.csv`**: Edges unique to each dataset (one file per dataset that has unique edges)
*   **`top_edges_comparison.csv`** / **`top_edges_overlap.csv`**: Top conserved/divergent edges and their overlap
*   **`degree_in.csv`** / **`degree_out.csv`** / **`degree_statistics.csv`**: Degree analysis by type
*   **`neuron_counts_by_type.csv`** / **`neuron_counts_summary.csv`**: Neuron counts per type and overall
*   **`motif_analysis.csv`**, **`threshold_sensitivity.csv`**, **`path_count_comparison.csv`**: Network motif, sensitivity, and path-count analyses

#### Visualizations (`comparison_visualizations/`)
*   **`edge_heatmap_{N}.png`**, **`path_heatmap_{N}.png`**, **`path_counts.png`**: Static heatmaps/counts per threshold
*   **`by_ratio/`** / **`by_probability/`**: Ratio and traversal-probability heatmaps (PNG + `data/` CSV)
*   **`visualization_data/`**: CSVs backing the report (`edge_overlap.csv`, `key_findings_per_threshold.csv`, `overlap_matrices_per_threshold.csv`, `path_counts.csv`, `path_heatmap_{N}.csv`, `edge_heatmap_{N}.csv`)

#### Similarity Matrices (`similarity_matrices/`)
*   **`similarity_threshold_{N}.csv`**: Cross-dataset similarity rows for threshold N

#### Dataset Data (`dataset_data/`)
*   **`{dataset_folder}/minsyn_{N}/`**: Raw `FindNeuronConnection` outputs per dataset/threshold (see Section 1), plus **`connections_edge.csv`** (raw edge list). Includes `hemisphere_symmetry/` and `find_reciprocal/` subfolders when those options are enabled.

## 8. Connectivity Profiling (ConnectivityProfileComparer)

The `ConnectivityProfileComparer` class (in `src/comparison/profile_comparator.py`) compares connectivity profiles within and across datasets.

> 📖 **See Also**:
> - [CONNECTIVITY_PROFILING](CONNECTIVITY_PROFILING.md) for complete usage documentation
> - [ConnectivityProfiler_Guide](core-features/ConnectivityProfiler_Guide.md) for profile construction details

### Folder Structure

`profiling_{FIRST_DATASET_ABBREV}_{query_name}_{ts}/`

Example: `profiling_MCNS_aMe_20260815_143922/` (query `aMe.*` over male-cns:v1.0 + flywire_FAFB_v783)

### Key Output Files

#### Overview
*   **`report.html`**: Overall HTML report linking every metric and heatmap
*   **`parameters.json`**: All analysis parameters (query, datasets, top_k/top_m, thresholds, metrics computed)
*   **`README.txt`**: Human-readable summary with the output structure

#### Intra-Dataset Results (`intra_dataset/{dataset_folder}/`)
*   **`results/similarity_{direction}_{metric}.csv`**: Type-level N×N similarity matrices
*   **`results/bodyid_similarity_{metric}_{direction}.csv`**: BodyId-to-bodyId comparisons
*   **`results/type_avg_bodyid_similarity_{metric}_{direction}.csv`**: Type similarities averaged from bodyId pairs
*   **`visualization/heatmap_intra_{direction}_{metric}.html`** and **`visualization/heatmap_intra_type_avg_{direction}_{metric}.html`**: Interactive heatmaps
*   Metrics: `jaccard`, `weighted_jaccard`, `cosine`, `rank_corr`, `rank_corr_union`, `combined`; directions: `upstream`, `downstream`, `combined`

#### Cross-Dataset Results (`cross_dataset/`)
*   **`mapping_summary.csv`**: Resolved type names per dataset with same-name flags
*   **`all_types/results/similarity_{direction}_{metric}.csv`**: N×M similarity matrices comparing the queried types across datasets
*   **`all_types/visualization/heatmap_inter_all_types_{direction}_{metric}.html`**: Interactive cross-dataset heatmaps

#### Profiles (`profiles/{dataset_folder}/`)
*   **`aggregated/{type}_profile.json`**: Type-aggregated connectivity profiles
*   **`individual/{bodyId}_{type}_profile.json`**: Individual bodyId profiles

## 9. NeuronBridge (EM↔LM Mapping and Co-Labeling)

The `NeuronBridgeFinder` class (in `src/neuronbridge_finder.py`) provides EM↔LM mapping via the NeuronBridge API and co-labeling analysis of driver lines.

> 📖 **See Also**:
> - [NeuronBridge_Guide](core-features/NeuronBridge_Guide.md) for complete usage documentation
> - [NeuronBridge_Workflow](core-features/NeuronBridge_Workflow.md) for step-by-step tutorials
> - [FlyLight_Guide](core-features/FlyLight_Guide.md) for image downloading

### 9a. FindLines Mode (`NB-find-lines_{ABBREV}_{query}_{ts}/`)

EM→LM mapping (driver lines matching EM neurons). Example: `NB-find-lines_MCNS_aMe12_20260815_145107/`

*   **`{query}_lines.csv`**: All matched driver lines with scores
*   **`line_summary.csv`**: Summary statistics per line
*   **`gal4_lexa_summary.csv`** / **`split_gal4_summary.csv`**: Per-library summaries (written when `separate_splitgal4=True`, the UI default)
*   **`images/`**: Downloaded CDM/FlyLight images (only when image download is enabled)
*   **`parameters.json`**: Analysis parameters

### 9b. FindNeuron Mode (`NB-find-neurons_{line}_{ts}/`)

LM→EM mapping (EM neurons matching a driver line). Example: `NB-find-neurons_SS01015_20260815_143937/`

*   **`all_neurons.csv`**: Combined matched neurons across all datasets
*   **`{line}_neurons.csv`**: Matched neurons for the line
*   **`{line}_{dataset_folder}_neurons.csv`** / **`{line}_{dataset_folder}_types.csv`**: Per-dataset matches and type aggregates
*   **`{line}_type_mapped.csv`**: Cross-dataset type mapping summary
*   **`labeling_distribution.html`**: Score distribution visualization
*   **`parameters.json`**: Analysis parameters
*   **`plot-3d_{dataset}/`**: Per-dataset 3D skeleton visualizations (only when `visualize_top_n > 0`)

### 9c. Co-Labeling Mode (`NB-colabeling_{lines}_{ts}/`)

Multi-line co-labeling analysis. Example: `NB-colabeling_SS01015_VT037867_SS46115_20260815_145150/`

#### Expression Matrices
*   **`expression_matrix.csv`**: Type × Line score matrix (types prefixed with dataset abbreviations, e.g. `MCNS_aMe12`, `FAFB_Dm4`, `HEMI_Unknown`)
*   **`expression_matrix_merged.csv`**: Same data with types merged across datasets (max score aggregation)
*   **`expression_matrix.html`** / **`expression_matrix_merged.html`**: Interactive heatmaps
*   **`expression_matrix_viz.csv`** / **`expression_matrix_merged_viz.csv`**: Reduced matrices for visualization

#### Co-Labeling Matrices
*   **`colabeling_matrix_jaccard.csv`** / **`colabeling_matrix_jaccard.html`**: Binary Jaccard similarity between lines
*   **`colabeling_matrix_weighted_jaccard.csv`** / **`colabeling_matrix_weighted_jaccard.html`**: Weighted Jaccard similarity

#### Labeling Distribution
*   **`labeling_distribution_by_type.html`** / **`labeling_distribution_by_neuron.html`** / **`labeling_distribution_stacked.html`**: Distribution visualizations
*   **`distribution_data_by_type.csv`** / **`distribution_data_by_neuron.csv`**: Raw distribution data

#### Supporting Data
*   **`labeling_info.csv`**: Case-sensitive type × Line matrix with dataset column
*   **`line_summary.csv`**: Summary statistics per line
*   **`line_labeled_neurons/`**: Per-line neuron details (`{line}_neurons.csv`, `{line}_{dataset_folder}_neurons.csv`, `{line}_{dataset_folder}_types.csv`, `{line}_type_mapped.csv`)
*   **`parameters.json`**: Analysis parameters
*   **`colabeling_report.html`**: Comprehensive HTML report
*   **`plot-3d_{dataset}/`**: Per-dataset 3D visualizations (only when `visualize_top_n > 0`)

### Expression Matrix Columns
- Row index: Neuron type (with or without dataset prefix)
- Columns: Driver line names
- Values: Maximum NeuronBridge match score (0-50000)

> 📖 **Score Interpretation**: See [NeuronBridge_Guide](core-features/NeuronBridge_Guide.md#match-types) for score thresholds and match quality interpretation.

### Merged vs Original Expression Matrix
| Aspect      | Original                   | Merged                        |
| ----------- | -------------------------- | ----------------------------- |
| Row index   | `MCNS_aMe12`, `FAFB_aMe12` | `aMe12`                       |
| Purpose     | Distinguish dataset source | Type identity only            |
| Aggregation | None                       | Max score across datasets     |
| Use case    | Dataset-specific analysis  | Cross-dataset type comparison |

## 10. FlyLight Image Downloader (FlyLightDownloader)

The `FlyLightDownloader` class (in `src/flylight_downloader.py`) downloads confocal images for driver lines.

> 📖 **See Also**: [FlyLight_Guide](core-features/FlyLight_Guide.md) for complete usage documentation.

### Folder Structure

`flylight-downloads_{lines}_{ts}/`

Example: `flylight-downloads_SS01015_VT037867_SS46115_20260815_145503/`
(Historical runs used the misspelled `flylignt-` prefix; that typo was fixed, and the UI still recognizes folders from older runs.)

### Key Output Files
*   **`{collection}/{line}/{image}_mip.png`**: Downloaded images, organized by collection and line (when `flat_structure=False`, the default). Image file names encode slide, sex, zoom, region, and driver type.
*   With `flat_structure=True`, images are saved directly into the run folder.
*   With `generate_summary=['pdf'|'pptx'|...]`, a summary document with the downloaded images is written into the same folder.

## 11. CrossDatasetTypeMapper (Type Mapping Utility)

The `CrossDatasetTypeMapper` class (in `src/comparison/cross_dataset_type_mapper.py`) provides automatic type name mapping across datasets.

> 📖 **See Also**: [AUTO_TYPE_MAPPING](AUTO_TYPE_MAPPING.md) for complete documentation of the type mapping system.

### Usage
This utility is used internally by `ComparisonAnalyzer`, `HomologFinder`, `ConnectivityProfileComparer`, and `NeuronBridgeFinder` when `auto_type_mapping=True`.

### Mapping Source
Type mappings are derived from the `male-cns_v1_0_allneurons_neuron_df.csv` file which contains columns:
*   `type`: Male-cns type name (canonical)
*   `flywireType`: Corresponding FAFB/FlyWire type name
*   `hemibrainType`: Corresponding Hemibrain type name
*   `mancType`: Corresponding MANC type name

### Priority Order
When resolving types, the priority is: male-cns > flywire > manc > hemibrain > optic-lobe

## Appendix: Output Column Reference

### Connection Data Columns

| Column                  | Description                     | Calculation                                                                                      |
| ----------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------ |
| `weight`                | Synapse count                   | Raw count from dataset                                                                           |
| `connection_ratio`      | Fraction of post-synaptic input | `weight / post_total` ([details](core-features/ScoreCalculation_Guide.md#connection-ratio))      |
| `traversal_probability` | Signal transmission probability | `min(1.0, ratio × 3)` ([details](core-features/ScoreCalculation_Guide.md#traversal-probability)) |
| `block_probability`     | Signal blocking probability     | `1 - traversal_probability`                                                                      |
| `nt_type`               | Neurotransmitter type           | ACH, GABA, GLUT, etc.                                                                            |

### Path Table Columns (`*_allpaths_type.csv`)

| Column         | Description                                     |
| -------------- | ----------------------------------------------- |
| `path`         | Path as a type sequence                         |
| `weights`      | Per-edge synapse counts along the path          |
| `probabilities`| Per-edge traversal probabilities                |
| `ratios`       | Per-edge connection ratios                      |
