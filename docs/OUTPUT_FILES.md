# Output Files Documentation

This document explains the output files generated by the core modules of the Hemibrain Connectomes Analysis pipeline.

## 1. FindNeuronConnection (Pathfinding)

The `FindNeuronConnection` class (in `src/coana.py`) is the core pathfinding engine. It generates a folder named `allpaths_...` containing all results.

### Folder Structure
The output folder name includes parameters used:
`allpaths_L{max_interlayer}w{min_weight}r{min_ratio}p{min_prob}_{timestamp}`

### Key Output Files

#### Connection Matrices
These files represent the connectivity between neurons or types in matrix format.
*   **`conn_mat_bodyId_weight.xlsx` / `.csv`**: Adjacency matrix of connection weights (synapse counts) between individual neurons (bodyIds).
*   **`conn_mat_type_weight.xlsx` / `.csv`**: Adjacency matrix of connection weights aggregated by neuron type.
*   **`conn_mat_bodyId_ratio.xlsx` / `.csv`**: Adjacency matrix of connection ratios (weight / total postsynaptic inputs).
*   **`conn_mat_type_ratio.xlsx` / `.csv`**: Adjacency matrix of connection ratios aggregated by neuron type.

#### Connection Lists (Edge Lists)
Detailed lists of all connections found in the paths.
*   **`conn_data_bodyId.csv`**: List of all edges between bodyIds. Columns: `bodyId_pre`, `bodyId_post`, `weight`, `type_pre`, `type_post`, `layer`, etc.
*   **`conn_data_type.csv`**: List of all edges aggregated by type.

#### Path Data
Lists of complete paths found from source to target.
*   **`path_data_bodyId.csv`**: All valid paths at the bodyId level. Each row is a path: `source -> node1 -> node2 -> target`.
*   **`path_data_type.csv`**: All valid paths at the type level.

#### Metadata & Structure
*   **`neuron_layers.json`**: A JSON file describing the layer-by-layer structure of the network (which neurons belong to Layer 0, Layer 1, etc.).
*   **`real_layer_map_bodyId.json`**: Mapping of each bodyId to its "real" layer (earliest appearance in paths).
*   **`real_layer_map_type.json`**: Mapping of each neuron type to its "real" layer.
*   **`parameters.txt`**: A text file recording all parameters used for the run.
*   **`all_attributes.json`**: A JSON dump of the `FindNeuronConnection` object attributes for debugging/reproducibility.

#### Visualization
*   **`visualization_output/`**: Subfolder containing HTML visualizations of the network (e.g., Sankey diagrams, graph plots) if generated. Real structure depends on visualization parameters.

## 2. VisualizeSkeleton (3D Visualization)

The `VisualizeSkeleton` class (in `src/coana.py`) generates 3D visualizations of neurons and synapses.

### Folder Structure
Outputs are saved in a timestamped folder: `plot3d_{layer_names}_{timestamp}`.

### Key Output Files
*   **`{layer_names}_plot.html`**: The interactive 3D visualization file. Open this in a web browser to view the neurons, synapses, and ROIs.
*   **`{layer_names}_neuron_info.xlsx`**: An Excel file containing:
    *   `neuron_df{i}` sheets: Metadata for neurons in each layer.
    *   `roi_count_df{i}` sheets: Synapse counts per ROI for neurons in each layer.
*   **`parameters.txt`**: Records the visualization parameters (colors, modes, backend, etc.).

## 3. HomologFinder (Inter- or Intra-Dataset Homologs)

The `HomologFinder` (in `scripts/FindHomologs.py` and `src/comparison/profile_comparator.py`) finds potential homologs across datasets.

### Key Output Files
*   **`bodyid_results.csv`**: The primary results file. Contains pairwise comparison scores between source neurons and candidate target neurons.
    *   Columns: `source_bodyId`, `target_bodyId`, `jaccard`, `cosine`, `rank_corr`, `combined_score`, `confidence`, etc.
    *   Sorted by `source_bodyId` and then `rank_corr` (descending).
*   **`type_summary.csv`**: Aggregated results at the neuron type level. Shows the best candidate type for each source type and average scores.
*   **`homolog_results.csv`**: A legacy format of the results, sorted primarily by rank correlation.
*   **`visualizations/`**: A subfolder containing 3D skeleton plots (HTML files) of the top homolog candidates, if `visualize_skeleton=True` was used.

## 4. ComparisonAnalyzer (Cross-Dataset Path Comparison)

The `ComparisonAnalyzer` (in `src/comparison/comparison_analyzer.py`) compares connectivity pathways across multiple datasets.

### Folder Structure
Outputs are saved in a user-defined output folder (default: `comparison_output/`).

### Key Output Files
*   **`comparison_report.html`**: A comprehensive, interactive HTML report summarizing the comparison. Includes:
    *   Summary statistics (conserved edges/paths).
    *   Detailed tables of conserved vs. unique connections.
    *   Sankey diagrams comparing flows.
*   **`comparison_report.txt`**: A plain text summary of the comparison results.
*   **`comparison_results.xlsx`**: A multi-sheet Excel file containing detailed data:
    *   `Summary`: High-level metrics.
    *   `Conserved_Edges`: Edges present in all datasets.
    *   `Unique_Edges`: Edges unique to specific datasets.
    *   `Path_Analysis`: Path conservation stats.
*   **`interactive_heatmap.html`**: An interactive heatmap visualizing the connection weights across datasets for all neuron pairs.
*   **`dataset_data/`**: A folder containing the raw `FindNeuronConnection` outputs (see Section 1) for each dataset and threshold analyzed. This allows for deep-diving into individual dataset results.
